# ShenZhi-Harvester

深知（ShenZhi）科研知识底座数据采集项目仓库。

## 项目定位

本仓库用于集中管理知识底座已有的数据采集与爬虫项目，
统一归档各成员的历史代码资产，便于后续维护、复用与集成。

当前阶段以资产归集为主，暂不要求统一技术架构或运行环境。

## 目录管理

- 每个独立项目在仓库根目录建立一个文件夹。
- 项目应尽量保留原有代码和目录结构。
- 不同项目之间保持相对独立。
- 暂不要求统一依赖、框架和数据处理方式。

示例：

```
ShenZhi-Harvester/
├── README.md
├── AGENTS.md
├── .gitignore
├── project-a/
├── project-b/
└── project-c/
```

## 项目提交要求

1. 每位成员将自己负责的已有项目上传至独立目录。
2. 每个项目提供 README.md，说明：
   - 项目名称及负责人
   - 数据来源与采集内容
   - 主要功能
   - 运行方法及依赖
   - 当前状态（可运行 / 部分可用 / 待验证）
3. 不提交密钥、环境变量、虚拟环境及无关临时文件。
4. 不随意修改其他成员负责的项目。

## 后续规划

完成历史资产归集后，统一开展代码盘点、能力验证，
再根据实际需求逐步进行公共能力抽取与工程集成。
